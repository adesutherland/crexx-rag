# Production rxjson projection replay

This Gate-1A replay consumes the installed `rxjson.jsondocument`. It does not
define another JSON class or a serialized vector envelope.

`node_f32_array` and `node_i64_array` return owning, headerless,
canonical-little-endian binary. The caller owns element type, count and
dimensional meaning in its application schema. The focused CTest runs
optimized and non-optimized compilation on both VMs and retains exact raw
commands, projection timings, checksums and the read-only binary-formal probe.
